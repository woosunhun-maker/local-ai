# H — 아이폰 문 (2.0)

기존 ChatGPT형 로컬 AI 앱을 지우고 처음부터 다시 만든 얼굴이다.

하는 일만 남겼다.

- 같은 집 와이파이에서 맥(`192.168.50.235:18791`)과 페어링
- 말은 맥으로 보내고, 답은 맥에서 흘려 받는다
- 대화 원본은 맥 디스크에만 둔다. 이 폰에 JSON을 쌓지 않는다

하지 않는다.

- 텔레그램 설정
- Codex / 성장 / 다른 AI 토글
- 칩·스파클·모드 선택
- 아이폰 로컬 대화 저장소

## 빌드

맥에서:

```
cd /Users/hun/Documents/로컬ai/secure-chat/ios
xcodegen generate
```

Xcode에서 아이폰을 고르고 설치한다. 번들 ID는 `com.hun.localai`라서 예전 앱을 덮어쓴다.

아이폰에서는 예전 앱을 삭제한 뒤 이 빌드를 올리는 것이 가장 깨끗하다.
