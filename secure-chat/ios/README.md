## 빌드

맥에서:

```
cd /Users/hun/Documents/로컬ai/secure-chat/ios
xcodegen generate
```

Xcode에서 아이폰을 고르고 설치한다. 번들 ID는 `com.hun.localai`라서 예전 앱을 덮어쓴다.
현재 소스 버전은 2.0.0 (build 4)이다.

아이폰에서는 예전 앱을 삭제한 뒤 이 빌드를 올리는 것이 가장 깨끗하다.
