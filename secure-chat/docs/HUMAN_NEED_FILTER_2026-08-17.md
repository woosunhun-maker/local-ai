# 사람이 필요한 것만 — 공개 자료 거름망

조사일: 2026-08-17  
출처: r/LocalLLaMA 공개 정리, HN Show HN, LM Studio LM Link 후기, Locally/PocketLLM 제품 설명.  
대화 원문·계정·토큰은 수집하지 않았다. 공개 페이지만 봤다.

## 넣을 것 (사람이 실제로 쓰는 것)

1. **맥이 생각하고 아이폰은 문만 연다.** 큰 모델은 Mac Studio Ollama. 폰에 모델을 받지 않는다. (LM Link와 같은 방향, 계정은 만들지 않음)
2. **한 방.** 채팅 목록·모드 칩·모델 고르기는 빼다. 말은 맥 디스크에만 남긴다.
3. **숫자 4자리 또는 맥 허용으로만 연결.** 클라우드 계정·Funnel·공개 인터넷 검색은 쓰지 않는다.
4. **열쇠는 키체인.** 앱을 다시 켜도 “연결 필요”가 뜨면 실패다.
5. **백그라운드 후 자동 재접속.** LM Link 후기의 가장 큰 불만. 일시 끊김으로 페어링을 지우지 않는다.
6. **보낸 말은 즉시 말풍선.** 키보드는 내려가지 않는다.
7. **스트리밍.** 답이 한 덩어리로만 오면 죽은 것처럼 보인다.
8. **텔레메트리·계정·구독 없음.**

## 빼는 것 (불필요하거나 위험)

- 결제·주문·송금, 메일/문자 보내기, 연락처·캘린더·위치 열기
- 에이전트가 아이폰 권한을 직접 쓰는 것 (Palmier형 폰 도구)
- 대화 원문을 클라우드·텔레그램·외부 AI로 넘기는 것
- HuggingFace에서 폰으로 모델 받기, 모델 고르기, ChatGPT 껍데기
- LM Studio 계정, Tailscale Funnel, 공개 포트
- CAPTCHA 우회, 호스트 탈출, 비밀 수집

## 이 저장소에 적용한 것

아이폰·맥은 `/api/room` 한 방만 본다. 401이 아니면 토큰을 버리지 않는다. 집 LAN(`192.168.50.235`)만 프록시한다.
기본 답은 맥 Ollama다. 일반 지식은 물어보라고 하지 않아도 맥이 `127.0.0.1:18790` 오픈에게 스스로 묻고, 교훈만 집에 남긴다. 인사·비밀·개인 기억은 보내지 않는다. API 키는 쓰지 않는다.
