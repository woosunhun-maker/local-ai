# rg가 뭐냐

`rg`는 **ripgrep**이다. Cursor가 코드에서 글자를 찾을 때 쓰는 로컬 검색기다. 브라우저가 아니고, 오픈에게 보내는 프로그램도 아니다.

이 맥에 있는 것:

- Cursor 에이전트 안의 `rg` (Anysphere 서명, ripgrep 15)
- Cursor 앱 안의 `@vscode/ripgrep`

## “데이터에 접근한다”는 뜻

폴더 안의 **파일 내용을 읽어서** `openai` 같은 단어를 찾는다.  
지금 이 대화에서도 로컬 AI 소스·설정을 그렇게 찾았다. 사진·키체인·문자 원문을 긁는 앱이 아니다.

맥이 “다른 앱의 데이터”라고 묻는 이유는, `rg`가 Cursor 본체가 아니라 **따로 떠 있는 실행 파일**이라서다. 프로젝트 폴더 읽기는 코딩에 필요하다.

## “네트워크에 접근한다”는 뜻

ripgrep 자체는 인터넷에 접속하지 않는다. 바이너리 안에 있는 `https://github.com/BurntSushi/ripgrep` 같은 글자는 **설명서 주소**일 뿐이다.

맥이 네트워크를 묻는 경우는 대개 다음이다.

- 검색 대상이 네트워크 디스크(NAS, iCloud, SMB)일 때
- Cursor 본체가 검색 **결과 몇 줄**을 이 채팅(클라우드 에이전트)으로 넘길 때. 그건 `rg`가 아니라 Cursor 쪽이다.

허용할 것: 이 저장소·로컬 AI 폴더 읽기.  
거부할 것: `rg` 단독 인터넷. 대화 원문·키·PrivateAI 데이터를 클라우드로 보내는 것.

로컬 AI가 Cursor를 부를 때 `rg`는 읽기 검색만 허용 목록에 있다. 커밋·푸시·배포는 없다.
