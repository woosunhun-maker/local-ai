# 가게 운영 통제 기준안 v0.1

상태: 사용자 제출정보 반영 초안  
작성일: 2026-08-08  
목적: 장현금·계좌·재고·카메라를 같은 영업일과 사건 ID로 연결하기 위한 최초 기준선

## 1. 확인된 운영 사실

- 연중무휴이며 오후 8시 오픈을 기준으로 영업일을 구분한다.
- 오전 마감 시각은 마지막 손님 퇴장 시각에 따라 달라진다.
- 장부 금액 단위는 만원이다. `469.9`는 4,699,000원이다.
- 영업 테이블은 1R~8R, 총 8개 룸이다.
- 장부 작성은 주로 매니저 민석·지민이 담당한다.
- 최종 마감 확인은 실장 하영이 담당한다.
- 현금·재고는 민석·지민이 취급하고 하영이 최종 확인하는 구조로 알려져 있다.
- 직원 1개 정산 단가는 11만원이다.
- 이모 시급은 1.5만원이며 4시간은 6만원이다.
- 직원 정산은 다음 영업 시작 전까지 카카오페이·계좌이체·현금으로 지급한다.
- 카메라는 캡스이며 약 9~10대, 휴대폰·Mac 조회 및 영상 다운로드가 가능하다.
- 카메라 열람 권한은 현재 사용자에게만 있다.
- POS는 현재 사용하지 않는 것으로 보인다.

## 2. 현재 기호의 의미와 충돌

### 기존 의미

- 동그라미: 계좌이체
- 세모: 카드
- 하트: 현금
- 빨간 동그라미: 여직원 선지급 또는 지급 완료 표시
- 빨간 X: 직원이 중간에 룸에서 빠져나옴
- X: 외상
- 체크 표시: 실제 계좌입금과 장부 금액을 대조해 일치 확인

### 즉시 수정할 충돌

`X`가 외상과 중도퇴실 두 의미로 사용되고 있어 자동 판독과 사람 검산 모두에서 오류가 발생한다.

새 표준은 다음과 같이 분리한다.

- 카드: `CARD`
- 현금: `CASH`
- 가게계좌 이체: `BANK`
- 외상: `CREDIT`
- 직원 중도퇴실: `EARLY-OUT`
- 직원 지급 완료: `PAID`
- 입금 검증 완료: `VERIFIED`

손기호는 보조로만 사용하고 영문 코드와 금액을 함께 적는다.

## 3. 금액 용어 정의

### 확인됨

- 와리: 손님 소개자 커미션
- RT: 손님에게 1건당 3만원을 받아 웨이터에게 지급하는 방비
- WT: 웨이터 팁
- 사비·시비: 사입비·지출비를 통칭하는 표현으로 사용됨
- 숙소비: 원거리 직원의 숙소 관련 지급

### 미확정

- 반개 정산 단가
- `기본 11.5`의 의미와 계산식
- 사비와 시비가 같은 항목인지 별도 항목인지
- 숙소비 지급 조건·정액·실비 여부
- `민석 2` 같은 추가금의 발생 근거와 승인자
- 와리 비율 또는 정액 계산식
- WT가 고객의 직접 팁인지 가게가 수납 후 전달하는 금액인지

미확정 항목은 증빙과 규칙이 정해질 때까지 자동 정산에 사용하지 않는다.

## 4. 장부 작성 필수 규칙

1. 모든 장부에 `영업일`, `룸 번호`, `작성자`, `마감 확인자`를 적는다.
2. 각 룸에 개별 `ROOM-EVENT-ID`를 부여한다. 예: `20260807-R02-01`.
3. 고객 입실·퇴실, 직원 입실·퇴실, 술 반입·회수, 결제를 사건 ID 아래 시간순으로 기록한다.
4. 금액은 `만원` 숫자와 실제 원화를 함께 적는다. 예: `55.0 / 550,000원`.
5. 카드·현금·가게계좌·외상을 금액별로 분리한다.
6. 계좌이체는 가게계좌 실제 입금이 확인된 뒤에만 `VERIFIED` 처리한다.
7. 빈 카드·현금·계좌·외상·총계 칸을 허용하지 않는다. 해당 없으면 `0`을 적는다.
8. 화이트·지우개·덮어쓰기를 금지한다.
9. 수정 시 기존 값을 한 줄로 취소하고 `수정값 / 이유 / 수정자 / 시각`을 남긴다.
10. 룸별 합계와 일마감 합계를 계산한 사람이 서명하고 하영이 재검산한다.
11. 장부 원본은 영업 종료 직후 전체 페이지를 촬영한다.
12. 사진은 자르거나 보정하지 않은 원본을 보존한다.

## 5. 결제 통제 규칙

1. 고객 계좌이체는 가게 공식계좌만 허용한다.
2. 직원·매니저 개인계좌로 받은 금액은 정상 결제로 인정하지 않는다.
3. 고객이 입금자명을 바꾸더라도 가게계좌 거래의 `입금 시각·금액·룸 ID`를 함께 대조한다.
4. 결제 완료는 직원의 휴대폰 화면이나 말이 아니라 가게계좌·카드 승인 원장을 기준으로 한다.
5. 카드 영수증은 룸 사건 ID를 적어 원본 사진과 연결한다.
6. 현금은 룸별 수납액을 적고 영업 종료 후 2인이 계수한다.
7. 현금 차이는 `예상 현금 / 실제 현금 / 차이 / 계수자 2인`을 기록한다.
8. 외상은 고객 식별번호, 승인자, 금액, 약속일, 회수일을 별도 외상대장에 기록한다.
9. 취소·환불·금액 변경은 원거래 ID, 이유, 처리자, 승인자와 시각을 남긴다.

## 6. 직원 정산 규칙

1. 룸별 근무시간과 개수·반개를 분리 기록한다.
2. 선지급은 지급 시각·금액·수단·지급자·수령 확인을 남긴다.
3. 카카오페이·계좌이체는 거래 화면 또는 내역의 참조정보를 연결한다.
4. 현금 지급은 지급자와 수령자가 각각 확인한다.
5. 숙소비, 소개 커미션, RT, WT, 기타비용은 직원 기본 정산과 별도 행으로 기록한다.
6. 증빙 없는 추가금은 `미확인` 상태로 남기고 총 지급액에 자동 포함하지 않는다.
7. 지급 완료와 장부 검증 완료를 서로 다른 상태로 관리한다.

## 7. 재고 통제 규칙

### 품목 코드

- `WINDSOR_ICE`: 윈저아이스
- `WINDSOR_HONEY`: 윈저허니
- `GOLDEN_BLUE_SAPPHIRE`: 골든블루 사피루스
- `GOLDEN_BLUE_DIAMOND`: 골든블루 다이아
- `UNOPENED`: 오픈하지 않은 술
- `A`: 의미 미확정 — 정의 전까지 별도 코드 유지

### 계산식

`시작 재고 + 매입 + 차입 + 반환받음 - 판매 - 서비스 - 파손 - 대여 - 반환함 = 마감 재고`

### 운영 규칙

1. 영업 시작 전과 종료 후 동일 품목·단위로 실사한다.
2. 시작 실사와 마감 실사는 서로 다른 2명이 확인한다.
3. 판매, 서비스, 파손, 대여, 차입을 각각 분리 기록한다.
4. `1BOX=6병`을 기본 단위로 사용하되 병 수를 함께 적는다.
5. 타 업소 차입·대여에는 상대업소, 품목, BOX, 병 수, 시각, 담당자, 반환기한을 적는다.
6. `M타운 원아 2BOX`는 `윈저아이스 12병 차입`으로 환산되지만 실제 품목과 반환 여부 확인 전에는 미결 항목으로 유지한다.
7. 서비스·파손 기록이 없는 재고 차이는 자동 중요 경보로 올린다.

## 8. 역할 분리

현재 민석·지민이 작성·현금·재고에 동시에 관여할 가능성이 있어 단독 통제가 약하다.

새 기준:

- 1차 기록: 근무 중 지정 매니저 1명
- 1차 현금 계수: 기록하지 않은 다른 담당자 1명
- 재고 실사: 매니저 1명 + 하영
- 최종 카드·계좌·현금·지급 검산: 하영
- 영상·원본 자료 감사: 사용자

같은 사람이 기록, 수정, 지급, 최종승인을 모두 수행하지 못하도록 한다.

## 9. 카메라 대조 원칙

1. 카메라와 장부의 시각 오차를 영업 시작 전 기록한다.
2. 룸 입실, 술 반입, 추가 반입, 회수, 손님 퇴실, 결제대 접근 사건만 우선 추출한다.
3. 영상상 병 수와 장부 반입·회수·판매·서비스 수량을 비교한다.
4. 카메라만으로 결제계좌의 목적지를 판정하지 않는다. 가게계좌 원장과 함께 검증한다.
5. 오디오는 현재 범위에 포함하지 않는다. 별도 법적·운영상 검토 전에는 활성화하지 않는다.
6. AI는 인물의 고의를 판정하지 않고 불일치 시각과 증거만 제시한다.

## 10. 최초 자동 경보

- 사용된 룸인데 장부가 없음
- 영상상 술이 들어갔지만 장부 수량이 없음
- 손님 퇴실 후 결제기록이 없음
- 계좌이체 표시가 있으나 가게계좌 입금이 없음
- 카드 표시와 카드 영수증 금액이 다름
- 장부상 현금과 실제 현금이 다름
- 화이트·덮어쓰기·수정자 없는 변경
- 숙소비·사비·WT·와리에 발생 근거가 없음
- 직원 지급 완료 표시와 실제 송금이 다름
- 타 업소 차입·대여의 반환 기록이 없음
- 시작·마감 재고 계산이 맞지 않음

## 11. 아직 필요한 결정

- 반개 정산 단가
- `기본 11.5`의 의미
- `A`의 실제 품목·상태
- 사비·시비의 구분
- 숙소비 지급 기준
- 와리·RT·WT의 승인자와 증빙 방식
- 카드 영수증 보관·번호 부여 방식
- 현금 계수 담당자 2인
- 재고 시작·마감 담당자와 실사 시각
- 외상 승인 권한자
- 캡스 장비 모델, 카메라 수, 보존기간, 시각 오차

이 값들이 확정되기 전에도 누락·산술·결제·수정·재고 장부의 기본 통제는 시작할 수 있다.
