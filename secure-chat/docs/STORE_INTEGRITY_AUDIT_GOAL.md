# 가게 운영 무결성 감사 프로그램 목표서

상태: **프로그램 목표 확정안 — 아직 카메라 연결·학습·운영 판정은 시작하지 않음**  
작성일: 2026-08-08

## 1. 최종 목표

장부, POS, 카드 승인, 현금, 지출 영수증, 재고, 직원 근무 기록과 가게 카메라의 시간대별 사건을 로컬에서 대조하여 다음을 조기에 발견한다.

- 기록 누락과 단순 계산 오류
- 카드·현금·테이블 매출 불일치
- 주문·제공·결제·장부 사이의 누락
- 병·상품·비품의 입고·사용·서비스·파손·반출 불일치
- 사후 금액 수정, 반복적인 반올림, 비정상 취소·환불·서비스 처리
- 특정 시간대·테이블·근무조에서 반복되는 손실 패턴

시스템은 사람을 범인으로 자동 판정하지 않는다. 결과는 항상 **불일치 후보와 근거 묶음**이며, 사용자가 원본 자료를 검토한 뒤에만 사실로 확정한다.

## 2. 핵심 원칙

1. **사람 판정이 아니라 사건 대조**  
   얼굴, 감정, 성격을 추정하지 않고 거래·물품·시간·장부 사건만 비교한다.
2. **오류와 부정을 분리**  
   누락이나 불일치는 먼저 실수, 절차 미준수, 시스템 오류, 고의 가능성으로 분해한다.
3. **AI 경보는 혐의가 아님**  
   독립된 자료 두 종류 이상이 일치해야 고위험 검토 대상으로 올린다.
4. **규칙 기반 우선**  
   처음부터 AI가 임의 학습하지 않는다. 계산식과 마감 규칙을 먼저 고정하고 정상 데이터를 축적한다.
5. **로컬 우선**  
   원본 영상, 얼굴, 직원 정보, 매출 자료는 Mac Studio 내부에서 처리하고 외부 AI에 전송하지 않는다.
6. **원본 불변성**  
   원본 사진·영상·POS 자료는 수정하지 않고 해시와 수집 시각을 기록한다.
7. **설명 가능한 경보**  
   모든 경보는 금액, 계산식, 관련 테이블, 영상 시각, 원본 위치와 판단 이유를 보여준다.

## 3. 데이터 입력

### 필수

- 날짜별 테이블 장부 원본 사진
- 실장이 작성한 당일 마감 메모
- POS 거래·취소·환불 내역
- 카드 승인 합계와 현금 마감액
- 매입·지출 영수증
- 품목별 시작 재고, 입고, 사용, 서비스, 파손, 대여, 반환, 마감 재고
- 직원 출퇴근·배정·정산 내역
- 카메라 원본 영상과 정확한 장치 시각

### 카메라에서 추출할 사건

- 테이블 착석·퇴장 시각
- 주문 또는 추가 주문이 발생한 시각
- 병이나 상품이 테이블로 이동한 수량과 시각
- 계산대 결제·취소·환불 시각
- 재고가 창고·냉장고에서 나오거나 외부로 이동한 사건

얼굴 식별, 감정 분석, 사적 대화 녹음은 기본 범위에서 제외한다.

## 4. 표준 사건 구조

모든 자료를 다음 공통 키로 연결한다.

- 영업일
- 사건 시각과 종료 시각
- 카메라 ID
- 테이블 ID
- 거래·영수증 ID
- 품목·수량
- 금액과 결제 수단
- 담당 역할 또는 내부 직원 ID
- 원본 자료 해시
- 정정 전 값, 정정 후 값, 정정자, 정정 이유와 시각
- 검증 상태: 미확인 / 일치 / 불일치 / 설명됨 / 재검토 / 확정

## 5. 탐지 규칙

### A. 마감 무결성

- 테이블별 합계 = POS 매출 합계
- POS 매출 = 카드 + 현금 + 승인된 외상·기타 결제
- 총매출 - 매입 - 지출 - 확정 정산 = 예상 잔액
- 빈 필드, 날짜 없는 장부, 수정자 없는 금액 변경을 자동 경보

### B. 거래·영상 대조

- 영상상 사용된 테이블인데 장부·POS 거래가 없음
- 병이 제공됐지만 주문·서비스·파손 기록이 없음
- 고객 퇴장 후 결제가 없거나 거래가 취소됨
- 동일 거래의 반복 취소·재결제·금액 축소
- 영업 종료 후 물품 반출 또는 계산대 접근

### C. 재고 대조

`시작 재고 + 입고 + 차입 - 판매 - 서비스 - 파손 - 대여 - 반환 = 마감 재고`

위 식의 차이를 날짜·품목·근무조 단위로 누적한다.

### D. 장기 패턴

- 특정 요일·시간·테이블·근무조에서 반복되는 차이
- 평균보다 높은 취소·환불·서비스·파손·반올림 비율
- 장부 수정 직후 발생하는 현금 차이
- 재고 차이와 매출 차이가 같은 날 함께 발생하는 패턴

상관관계만으로 사람의 고의를 판정하지 않는다.

## 6. 학습 단계

### 0단계 — 기준 정의

용어, 가격, 수당, 와리·RT·WT·사비·숙소비, 반올림, 재고 단위를 확정한다.

### 1단계 — 30일 정상 데이터 축적

OCR 결과를 사람이 교정하고 일별 장부·POS·재고·영상 사건을 연결한다. 이 단계에서는 규칙 기반 경보만 사용한다.

### 2단계 — 60~90일 기준선 학습

요일, 시간대, 테이블, 품목별 정상 범위를 학습한다. 사용자의 `정상 / 실수 / 설명됨 / 조사 필요` 판정을 정답 라벨로 사용한다.

### 3단계 — 영상 사건 자동 추출

테이블 점유, 병 이동, 결제대 접근 등 필요한 사건만 추출한다. 원본 영상 전체를 모델 기억에 넣지 않는다.

### 4단계 — 장기 이상탐지

단일 사건보다 반복 패턴을 우선한다. 모델 변경 전후에는 과거 데이터 재검증과 오탐 비교를 수행한다.

## 7. 경보 등급

- **정보**: 필드 누락, 흐린 사진, 날짜 불명
- **주의**: 단일 자료의 계산 불일치 또는 설명 없는 수정
- **중요**: 서로 다른 두 자료에서 같은 거래 불일치
- **긴급 검토**: 영상·POS·현금·재고 중 세 자료 이상이 동일 손실 사건을 가리킴

긴급 검토도 자동 비난·급여 공제·징계·해고로 이어지지 않는다.

## 8. 성공 기준

- 날짜·카드·현금·총계·수정자 필드 누락 탐지율 100%
- 장부 산술 검산 정확도 100%
- POS·카드·현금 일마감 대조율 100%
- 카메라와 POS 시각 오차 2초 이하 유지
- 고위험 경보에는 독립 증거 두 종류 이상 첨부
- 경보마다 계산식과 원본 위치 제공
- 사용자 확인 없이 인물별 혐의 점수나 블랙리스트를 만들지 않음
- 외부 AI로 원본 영상·얼굴·매출·직원정보 전송 0건

머신러닝 정확도 목표는 실제 라벨 데이터가 쌓이기 전에는 숫자로 약속하지 않는다. 최초 60일 동안 오탐률을 측정한 뒤 운영 기준을 정한다.

## 9. 개인정보와 증거 안전장치

- 촬영 목적, 범위, 보관기간, 접근자를 문서화하고 안내 표지와 운영·관리 방침을 점검한다.
- 화장실, 탈의 공간 등 사생활 침해 구역은 절대 촬영하지 않는다.
- 음성은 기본적으로 수집하지 않는다.
- 영상 열람·내보내기·삭제를 모두 감사 로그에 남긴다.
- 일반 영상은 목적에 필요한 기간만 보관하고, 경보 구간은 사건번호와 해시를 부여해 별도로 보존한다.
- 원본 접근 권한과 분석 모델 권한을 분리한다.
- 직원별 통계는 사용자가 승인한 감사 목적에서만 열람한다.

## 10. 첫 구현 범위

첫 버전은 카메라 AI부터 만들지 않는다.

1. 장부 사진 수집 및 원본 해시
2. OCR 전사와 사용자 교정
3. 날짜별 카드·현금·POS·지출·재고 입력
4. 자동 산술 검산과 누락 경보
5. 영상 시각 링크를 수동으로 붙이는 사건표
6. 일일 감사 보고서와 주간 반복 패턴 보고서

이 단계에서 자료 구조와 계산 규칙이 검증된 뒤에만 카메라 사건 자동 추출을 추가한다.

## 11. 최종 산출물

매일 다음 형식으로 보고한다.

- 확인된 정상 항목
- 누락 자료
- 계산 불일치
- 영상과 거래의 불일치 시각
- 가능한 원인: 실수 / 절차 문제 / 시스템 문제 / 고의 가능성
- 추가로 필요한 증거
- 사용자 최종 판정

프로그램의 최종 목적은 사람을 감시하는 것이 아니라 **돈·재고·기록의 흐름을 설명 가능하게 만들어 가게의 손실을 줄이는 것**이다.
