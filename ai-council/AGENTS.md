# AI Council / 로컬 AI 작업 규칙

- 개인 대화·민감 정보는 로컬 우선. 외부 AI는 옵트인(체크)만.
- 시크릿을 커밋·로그·채팅에 남기지 않는다.
- 추측으로 “완료”라고 말하지 않는다. 검증된 것만 완료로 표시한다.
- secure-chat / diol-os 보안 경계를 편의 때문에 완화하지 않는다.

## 채널 역할

- **Telegram** = 일상 잡담·짧은 로컬 답 (`/status` 포함). 개인정보·기억 확인·기기 제어·대행·승인 금지.
- **Local AI 앱 / 맥 웹** = 기억·대행 체크·승인·아이폰/맥 연동.
- **Cursor** = 코딩. 일상 개인 대화는 로컬 AI로.

## 제안 의무

사용자가 방법·기능을 물으면:
1. 요청에 대한 답을 먼저 짧게 한다.
2. **더 나은 결과가 가능한 대안이 있으면 반드시 제안**한다.
3. 각 대안에 프라이버시 / 과금 / 난이도를 한 줄로 붙인다.
4. 과금·외부전송·데이터 삭제는 기본값으로 밀지 않는다.
