# 채널 역할 (확정)

| 채널 | 하는 일 | 안 하는 일 |
|------|---------|------------|
| **Telegram** | 일상 잡담, 짧은 로컬 답, `/status` | 개인정보·기억 확인·아이폰/맥 제어·대행·승인 |
| **로컬AI 앱 / 맥 웹 (`18792`)** | 기억 확인, 대행 체크, 승인, 기기·맥 연동, Codex 초안 요청 | Cursor IDE의 Run 버튼을 대신 누르기 |
| **Cursor** | 코딩 | 일상 개인 대화 |

규칙
- Telegram → Mac 로컬 Ollama만 (도구/기억확인/제어 없음)
- **작업 요청** (“해줘/장바구니…”) → 앱 승인 카드 자동 생성 → 승인 후 Mac 안전 실행
- 결제·비밀번호·계좌 등 민감은 **사람 직접** (승인·실행 파이프에 안 넣음)
- Cursor Run이 뜨기 직전 → 로컬AI 앱으로 **알림만** (폰에서 Run 대행 불가, 맥에서 누름)
- 앱에서 보낼 수 있는 지시: Mac 로컬 대화·기억·웹작업 승인·Codex 점검/초안. Cursor 채팅창에 자동 타이핑은 없음
- 대행 질문은 앱/웹에서 체크 ON일 때만
