# 로컬 AI 세계 기준 취합 + 우리 제품 결정

작성: 2026-08-14  
원칙: 사용자가 물을 때 **더 나은 길이 있으면 반드시 제안**한다.

---

## 1. 전 세계 로컬 AI에서 공통으로 쓰이는 스택

| 층 | 정석 | 우리 현황 |
|----|------|-----------|
| 추론 엔진 | Ollama / LM Studio | Ollama ✅ |
| 채팅 UI | Open WebUI | Open WebUI ✅ + 자체 웹/아이폰 |
| 문서 지식(RAG) | AnythingLLM 또는 Open WebUI+pgvector | 약함 / 나중 |
| 원격 접속 | Tailscale (공인 노출 금지) | Tailscale ✅ |
| 보안 | loopback 바인딩, Funnel 금지, 인증 | 대체로 ✅ |
| 기억 | 채팅 기록 ≠ 장기 프로필 기억 | **확인형 MVP 활성** (아이폰·맥 웹 공유) |

---

## 2. 넣어야 하는 것 (Must)

1. **확인형 장기기억** — 어디서 대화해도 같은 ‘나’  
   - 후보 → 사용자 확인 → 활성  
   - Keychain/암호화, 만료, 외부공유 허용 플래그 분리
2. **보내기 직전 체크** — 「다른 AI에게 대신 물어보기」(자동 판단 금지)
3. **로컬 기본 답변** — 체크 없으면 데이터 밖으로 안 나감
4. **Ollama loopback only** — `127.0.0.1` 유지, 인터넷 직접 노출 금지
5. **원격은 Tailscale만** — Funnel/공인 포트 열지 않음
6. **상시 서버** — Terminal에 의존하지 않는 KeepAlive (PrivateAI 경로 등)
7. **민감정보 가드** — 대행 질문 전 차단/마스킹
8. **한 줄 상태표시** — `로컬만` / `기억 N` / `대행 ON`

## 3. 넣으면 좋은 것 (Should)

1. Open WebUI를 **채팅 껍데기**, 기억·대행·승인은 **우리 서버가 주인**
2. 로컬 멀티모델 대조(`--council`) — 키/과금 없이 품질 보강
3. 문서 RAG(AnythingLLM 또는 pgvector) — “파일 지식”만 분리
4. 음성 입력(맥 받아쓰기 / 아이폰 마이크)
5. 백업: 기억 catalog + 설정만 암호화 백업
6. 모델 역할 분리: 대화 모델 vs 도구/에이전트 모델
7. MCP/도구는 **allowlist + 승인** 뒤에만

## 4. 굳이 넣을 필요 없는 것 (Could skip)

1. API 키 기반 유료 OpenAI/Gemini를 **기본 경로**로 쓰기
2. ChatGPT식 프로젝트/폴더 강제 구조
3. 멀티유저 SSO/LDAP (1인 홈랩에 과함)
4. 얼굴인식·상시 마이크·방 안 카메라
5. Telegram에 개인정보·기억 확인·기기 제어까지 몰아넣기
6. 자동 “깊은 질문 → 외부 전송”
7. 처음부터 완벽한 에이전트/쇼핑/폰 자동화 올인원

## 5. 채널 역할 (확정)

| 채널 | 하는 일 | 안 하는 일 |
|------|---------|------------|
| **Telegram** | 일상 잡담, 짧은 로컬 답, `/status` | 개인정보 저장·기억 확인·아이폰/맥 제어·대행 질문·승인 |
| **Local AI 앱 / 맥 웹** | 기억 확인, 대행 체크, 승인, 기기·맥 연동 | (일상 잡담도 가능하지만 필수는 아님) |
| **Cursor** | 코딩 | 일상 개인 대화 |

## 6. 빼면 좋은 것 (우리 제품 기준)

| 항목 | 이유 |
|------|------|
| 첫 화면의 Codex/성장/폰자동화 복잡 UI | 일상 대화 방해 |
| Telegram을 제어·승인·기억 허브로 쓰기 | E2E 아님, 유출면 큼 |
| 자동 deep 라우팅으로 외부/도구 확대 | 사용자 의사와 불일치 |
| API 키를 필수처럼 안내 | 과금·오해 |
| Terminal 열어둬야 하는 웹서버 | 원클릭 KeepAlive로 대체 |
| 대화방=기억 폴더 모델 | “언제든 빠딱”과 반대 |

> 코드 삭제는 단계적으로. 먼저 **기본 UX에서 숨김/비활성**, 안정 후 정리.

## 7. 주의할 점 (세계적으로 반복되는 실패)

1. Ollama를 `0.0.0.0`으로 열고 인증 없음 → 스캔/남용
2. “로컬”이라며 UI 텔레메트리·클라우드 임베딩을 기본 ON
3. RAG에 비밀번호·주민번호·대화 원문 무분별 적재
4. 에이전트에 파일/쉘/결제 권한을 기본 부여
5. 모델이 기억·사실을 **확인 없이** 단정
6. 아이폰 개발 서명 7일 만료(Personal Team)로 앱이 갑자기 죽음
7. 백그라운드 서버가 세션 종료와 함께 죽음 → launchd/KeepAlive 필수
8. “여러 AI 대조” = 곧 API 과금이라고 착각 (브라우저 대행/로컬 멀티모델 대안 있음)

## 8. 우리 목표 아키텍처 (확정)

```
Telegram (일상 잡담 입구) ──→ 로컬 Ollama만 (도구/기억확인/제어 없음)
Local AI 앱 / 맥 웹 ────────→ 맥 Local AI 코어 (진실)
    ├─ 기본: Ollama 답 + 활성 기억
    ├─ 체크 ON: 대행 질문 (브라우저/옵트인) + 공유허용 기억만
    └─ 승인·아이폰/맥 연동 제어
```

Open WebUI = 참고·보조 UI  
Telegram = 일상 입구  
secure-chat 앱/맥 웹 = 개인·제어·기억 본선  
ai-council = 대행/대조/기억 API 실험·코어
